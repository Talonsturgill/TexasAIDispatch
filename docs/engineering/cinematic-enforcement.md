# Cinematic production enforcement

New editions from September 25th, 2026 require the versioned cinema plan, a dimensional opening
and the policy's minimum dimensional story coverage. Whole-film quarter-scale animatics remain
useful but no longer substitute for an approved full-resolution hero scene with sound.

The proof builder renders the actual Dispatch composition and repeats board-event frames with
only CinematicStage removed. The checker recomputes visible pixel contribution and action change,
binds the board, engine, policy and mix, and compares those frames with the final encoded film.
An unused import, hidden stage or declared renderer name cannot satisfy the pixel check.

Three independent scoring agents keep their existing responsibilities. Each receives a separate
picture, story or sound audiovisual provider response bound to the exact final MP4. The gate
requires timestamped audio and visual observations, separate response identities and each
judge's receipt hash. Provider failure, missing audio access or a rejected film blocks release.
These are audiovisual model observations, never a claim of human listening or measured retention.

The renderer, preship, panel aggregation, ship gate, controller terminal transition, delivery and
feed publication enforce the new contract. CI also checks changed run packages directly, so
hand-committing an unproven edition does not skip review. Historical artifact rewrites and new
backdated editions are refused there. Already published media remains byte-identical.

The mixer now uses explicit reported compression and two-pass dynamic loudness mastering after
refusing a clipped source sum. It verifies unchanged sample count and measures output again.
The final AAC is independently measured at release. All existing pacing windows remain intact.

## Verification recorded during implementation

- Synthetic full-resolution media exercises valid proof, stale board/engine/policy/mix hashes,
  missing proof, an unused stage, substituted final pixels, duplicate reviewer identities,
  edited provider evidence, missing audio and a high score without production evidence.
- A temporary Git repository exercises the changed-run CI path with a manually committed
  unproven film. It is rejected.
- The actual shared WebGL stage was rendered normally and removed at the same frame. Its
  measured visible contribution was 0.16527 of the frame. This checks wiring, not artistic merit.
- An unpublished copy of September 24th audio measured -22.27 LUFS before treatment. Its mastered
  WAV measured -16.96 LUFS and -1.99 dBTP. The final AAC test measured -16.97 LUFS and -1.87 dBTP.
  All 2,064,000 samples at 48 kHz were retained. No published media was replaced.
- An actual Gemini 3.8 Flash audiovisual request observed sound in a seven-second optical-study
  clip and rejected its weak camera-led development. The gate returned failure. No passing
  creative verdict was substituted. An earlier provider request returned HTTP 404 and was also
  recorded as spent without approval.

The exact future daily film still needs to pass its own tests. Pixel coverage cannot establish
taste, prove every mechanical interpretation or guarantee that viewers will watch.
