# Agent routing and measured efficiency

Effective for newly planned editions from October 10th, 2026. Earlier shipped editions and
unfinished frozen allocations retain their original evidence. The saved director remains
GPT-6.1-sol at medium effort. The sole assignment authority is config/agent_runtime.json.

Use the existing roles. A narrowly scoped researcher and voice director use Luna at high
effort. The validator, builder and critic use Sol at high effort for source limits, causal
implementation and comprehensive defect discovery. The three separate final scorers retain
Sol at medium effort, the current guide text and hashes, the exact film and fixed rubric.
Gemini audiovisual review, continuous Gemini TTS, built-in ImageGen and measured alignment
retain their current configured providers. Renderers, gates and bookkeeping are local tools.
Their settings are not Codex reasoning effort. No additional daily agent or panel is created.

## Prepare an assignment before paying for it

Generate the current compact packet. Research uses --input-packet --role researcher with the actual movement
record and applications reference; the worker searches those bound files for its one assigned
beat. Other roles use daily_production.py --packet. The scene-builder packet is the director's
existing two-treatment assignment, including the actual fresh raster assets and source limits.
Generate --plan with the packet, a unique task name and a concise scope. The planner verifies
all hash-bound references, the current brief and policy, and supplies explicit spawn arguments.
Reserve the existing resource before executing those arguments. Panel reservations remain
atomic for exactly three scorers. A plan neither calls a model nor reserves capacity.

Start workers with fork_turns none. Passing the director's accumulated conversation to each
worker repeats expensive context and carries the director's defense into independent review.
The packet points to complete current guides; never shorten their required contents to save
input. For follow-ups, attach only the current packet, changed inputs, exact retained failures
and one consolidated correction. Keep one render owner. Do not spawn a new critic for each
individual symptom or run competing render commands. Reuse unchanged evidence only through
the current dependency and exact-byte cache validators, including retained rejections.

Prefer one promising researched beat. Expand within the existing allowance only when that
candidate fails the source or filmability screen. A small model's work still receives the
independent source validator and exact-film gates. Inaccessible or incomplete evidence gets
one concrete diagnosis and the existing charged recovery path. Never repeat an identical
failed request or quietly replace its evidence. Observed host unavailability still follows
review-availability.md and the configured independent provider; cheaper model routing does
not authorize that provider as the normal review path.

For configured provider recovery on these new editions, carry every current guide and source,
the exact current film, complete receipts and all unique native pictures. The previous edition
is supplied as a SHA-256-bound media inventory with original artwork provenance and scene
picture records, rather than its unrelated full narration and director rationale. Verify all
media aliases, then attach identical bytes once while preserving each path and hash. This
changes neither native resolution nor frame sampling. Historical packets and verdicts retain
their original transport evidence.

## Find all defects before the next expensive operation

The builder delivers both complete treatments, clause-by-clause subject/action/result/limit
coverage, tested event joins, correct regional background and caption clearance together.
Run the existing mechanical board, source, modern-film, art, staging and caption-fit checks
before consuming a critic or preview reservation. The critic returns one complete list of
source, recognition, motion, framing, surface and ending defects. It watches before reading
the director's explanation. Every current mandatory observation remains required.

Before voice, read the full approved passage aloud as connected phrases and flag ambiguous
pronunciation or word grouping for source validation in one correction. Do not synthesize an
unused alternative. Preserve a good voice take and measured alignment across picture repairs.
Higher builder/critic effort aims to catch linked defects in the first correction rather than
paying for serial small fixes. After two rejections of a mechanism, use the existing independent
source-backed pivot; never buy optional polish past the protected completion boundary.

A validator can verify every claim. An empty rejected list is valid when independently fetched
sources support them all. Do not invent a rejection to satisfy a quota. Missing, false or
scope-expanded claims still fail and remain in the original evidence.

## Record observations without inventing savings

At release and recovery checkpoints run agent_runtime.py --audit-session with the exact local
root-session path, --through with the checkpoint's UTC timestamp, and --out under out/dispatch.
The audit finds direct child sessions in that session's day folder, uses the final cumulative
counter once per session, and records actual model/effort and spawn choices. It outputs counts
and hashes, never conversation prose or credentials. Preserve the audit privately. Do not
add reasoning output to output tokens or cached input to input tokens a second time.
Missing counters remain unknown. The collector never replaces controller/provider charges.

Run --measure after shipment. Compare the two shipped baseline editions with the next five
new editions, including unfinished attempts. Record agent/provider usage separately, repair
and preview counts, first-panel acceptance, actual rubric scores, elapsed time and verified
shipment. Keep --audit-session output separate from the public report. Dollar cost remains
unknown without billing evidence; token telemetry is not a subscription invoice. One tenth
cost and tenfold quality are owner targets, not measured facts. A tooling test proves routing
and failure detection, not a better audience experience. All mandatory gates stay unchanged.
