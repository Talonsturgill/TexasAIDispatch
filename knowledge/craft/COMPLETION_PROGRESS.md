remain unchanged. Preserve the three-round creative boundary, every charge and actual failure.

Consolidate every failure and all uses of that implementation in the same replacement.
Keep the retired files and all rendered evidence intact. Retired modules must leave the
actual renderer import closure; the replacement must enter it. A copied file with renamed
identifiers, coordinates, colours, string literals or easing values is refused. A previously
failed replacement path cannot reenter under another mechanism name. The controller checks
admission before granting capacity and opening a repair, then verifies the real closure before
authorizing capture. Independently classified technical corrections keep their existing scope.
An unchanged best cut can still proceed through the evidenced bounded release route.

Keep the evidence scopes distinct. The code packet binds its decision boundary before the
caller can reserve the reviewer. A source contradiction, missing executable action, invalid
dependency or provable bounds failure can block capture. An unresolved implementation of an
actual retained film defect also remains a blocker. Perceived foam, cabin recognition, apparent
speed and surface beauty need current pixels; an unrendered preference cannot start another
code repair. Carry that uncertainty to the existing exact-film review. Consolidate all
code-proven defects together. This adds no reviewer or assignment and changes no role model.

This supplies no review pass. Modern action, finish, timing, source, rights, caption, sound,
native PNG/CRF16, independent scoring and every shipment gate remain required. A fallback must
pass its actual current reviews. Do not ask the owner to choose an internal recovery route.

Paid native subagents run in the background with the existing role model and effort. When
the actual Stop payload reports a running named subagent matching its durable owned reservation
claim, the continuation helper retains a wait receipt and yields to the native completion
notification. It leaves the controller unfinished and does not release publication ownership.
Do not poll the worker, send periodic status messages, sleep in a model-driven loop or create
another monitor. On the native completion event, collect the original handback and continue
the same edition. A failed or missing task, unknown type, monitor, shell sleep or unfunded
claim cannot authorize that yield. Without a verified native wake, retain the existing
bounded wait and unfinished-production guard.

A second routine that receives `busy` after the startup helper's one bounded ownership wait
ends as an observer without restoring, arming, paying, polling or claiming shipment. The
active owner completes the oldest unfinished edition and then any due current-day edition
sequentially. Never keep a second model conversation alive solely to watch the publisher.
